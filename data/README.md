# 演示数据说明

本目录所有告警、IP、域名、IOC 均为**合成数据**，用于毕业设计演示：

- `203.0.113.0/24`、`198.51.100.0/24`、`192.0.2.0/24` 是 RFC 5737 文档保留地址；
- 示例域名使用 `.example` / `.test`；
- `iocs.csv` 中的哈希是随机占位值，不对应真实恶意样本；
- `sample_alerts.json` 是 Wazuh 告警的简化格式，不是从真实 Wazuh 集群导出的；
- `mock_alerts.json` 额外带 `_demo_offset_minutes` 字段，仅用于 mock 后端生成“最近 15 分钟”的相对时间。

不要把本目录的数据当作真实威胁情报使用。
